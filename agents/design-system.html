Design system — v1

Two rooms, one language

A host's projector and a guest's phone are different rooms with different needs — one is read from across the room, one is held in a hand. The system below designs them separately, but ties them together with the same type, color, and motion vocabulary so the product still feels like one thing.

Principles

The load-bearing decisions everything else follows from.

Legible across a roomStage type is sized and weighted to be read from the back of a conference room on a projector, not just a laptop demo.
Two modes, one systemStage (dark, presenter) and Pocket (light, participant) look different on purpose, but share the same typefaces, accent colors, and motion so they read as one product.
Live feels aliveOne deliberate motion vocabulary — count-up numbers, filling bars, a pulsing live dot — not hover effects scattered across every element.
Corporate-safe energyPlayful enough for a Friday game night, restrained enough for an HR lead to put in front of the whole company.

Color

Built from a stage-lighting idea, not a generic brand palette. Gold marks the thing that's active; violet marks the thing that's live right now — the two are never interchangeable.

What this avoids

Choices made deliberately against the defaults, so they don't drift back in later.

Instead of
Warm cream + serif display + terracotta accent
This uses
Warm paper + grotesk display, and gold that's clearly amber, not terracotta
Instead of
Near-black background + one neon accent
This uses
A violet-tinted stage color with two accents doing different jobs, not one neon doing everything
Instead of
Identical rounded cards with the same soft shadow everywhere
This uses
Flat bordered cards on Stage (no shadows on a projector), soft elevation only on Paper
Instead of
ALL-CAPS eyebrows, arrows on every button, middle-dot meta strings
This uses
Sentence case throughout, arrows only where something actually navigates away
